# Компонент SettingsMenu

# Компонент SettingsMenu — это адаптивное меню настроек, отображающее список управляющих пунктов: редактирование профиля, чёрный список, поддержка и выход из аккаунта. Предназначен для использования на странице настроек приложения.

# Состав

Ссылки на разделы настроек (/settings/profile, /settings/blacklist, /settings/support)
Пункт «Выйти из аккаунта» с подтверждением через модальное окно
Полная поддержка адаптивного дизайна (мобильные и десктопные экраны)
Состояние активного пункта на основе текущего маршрута
Поддержка доступности (aria-label, фокус-навигация)

🖼️ Внешний вид
Единый карточный блок с закруглёнными углами на десктопе, без закруглений на мобильных
Каждый пункт содержит иконку, текст и стрелку вправо (кроме «Выйти»)
При наведении (только на десктопе) и при активном состоянии — подсветка фона
На мобильных устройствах все пункты, включая последний, имеют нижнюю разделительную линию

🧩 Использование
import { SettingsMenu } from '@/features/SettingsMenu/ui/SettingsMenu';

export default function SettingsPage() {
return (

<div className={styles.container}>
<h1>Настройки</h1>

}**

Поддерживает передачу дополнительного класса:

<SettingsMenu className={styles.customMenu} />

⚙️ Конфигурация
Меню настраивается через файл конфигурации:

app/settings/shared/model/settingsMenu.ts

Поддерживаются следующие параметры для каждого пункта:

id — уникальный идентификатор
label — отображаемый текст (на русском)
title — значение для aria-label (на английском)
Icon — компонент иконки (SVG)
href — путь (если не указан — пункт обрабатывается как «Выйти из аккаунта»)
💡 Пункт «Выйти из аккаунта» не требует href — его наличие автоматически делает элемент кнопкой с логикой выхода.

📱 Адаптивность

# На десктопе (> 768px):

Закругление блока: 12px
Отступы внутри пунктов: 14px 10px
Нижняя граница: отображается у всех пунктов кроме последнего
Hover-эффект: подсветка фона при наведении мыши
Кнопки в модальном окне: выровнены по правому краю, компактные (90×32 px)

# На мобильных (≤ 768px):

Закругление блока: отсутствует (border-radius: 0)
Отступы внутри пунктов: 24px 10px 24px 0
Нижняя граница: отображается у всех пунктов, включая последний
Hover-эффект: отключён (применяется только на устройствах с мышью)
Кнопки в модальном окне: выровнены по центру, увеличенные (137×44 px)

🔒 Логика выхода
При клике на «Выйти из аккаунта» открывается модальное окно подтверждения
Подтверждение вызывает хук useLogout из @/shared/lib/hooks/useLogout
Отмена закрывает модалку без действия
Модальное окно адаптивно: на мобильных кнопки центрированы и увеличены

🎨 Стили
Использует CSS-переменные из дизайн-системы (--color-white, --hover-settings-links, и др.)
Подключает миксин focus-visible для улучшенной навигации с клавиатуры
Все стили изолированы через CSS Modules

🧪 Зависимости
next/link, next/navigation
react, useState
Общие UI-компоненты: Button, Text, Modal
Иконки: Edit, BlackList, Support, LogoutIcon, Forward
Хук: useLogout

✅ Best Practices
Единый источник конфигурации (avoid duplication)
Семантическая разметка (<Link>, <button>)
Доступность (ARIA, фокус, медиа-запросы для hover)
Чистая логика: определение «logout» по отсутствию href
Адаптивный дизайн без JS-условий
