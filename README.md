## 📌 Описание проекта

Проект представляет собой веб-приложение, разработанное с использованием **Next.js (App Router)** и современного стека для управления состоянием и архитектуры.

В основе проекта лежит архитектурный подход **Feature-Sliced Design (FSD)**, обеспечивающий масштабируемость, читаемость и удобство поддержки кода.

---

## 🛠️ Технологии

* **Next.js (App Router)** — серверный рендеринг, маршрутизация и оптимизация
* **React**
* **TypeScript** — строгая типизация
* **Redux Toolkit (RTK)** — управление глобальным состоянием
* **RTK Query** — работа с API, кэширование и синхронизация данных
* **react-hook-form** — работа с формами, валидация полей
* **SCSS / CSS Modules** — стилизация компонентов
* **ESLint + Prettier** — контроль качества и форматирование кода

---

## 🧱 Архитектура проекта

Проект построен по методологии **Feature-Sliced Design (FSD)**.

Основные слои:

```
src/
├── app/        # Инициализация приложения, layout, providers, роутинг
├── pages/      # Страницы приложения (если используются)
├── widgets/    # Составные UI-блоки
├── features/   # Бизнес-фичи (логин, формы, действия пользователя)
├── entities/   # Сущности предметной области (user, product, cart и т.д.)
├── shared/     # Переиспользуемые компоненты, утилиты, ui-kit
```

Каждый слой изолирован и взаимодействует только с разрешёнными уровнями, что упрощает поддержку и развитие проекта.

## 🚀 Запуск проекта

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

### Сборка проекта

```bash
npm run build
```

### Запуск production-сборки

```bash
npm start
```

---

## 📦 Работа с состоянием и API

* Глобальное состояние управляется с помощью **Redux Toolkit**
* Запросы к серверу реализованы через **RTK Query**
* Используется кэширование, автоматическое обновление данных и обработка состояний `loading / error / success`

---

## 🧪 Качество кода

* Настроены **ESLint** и **Prettier**
* Используется единый стиль кода
* Проект готов к масштабированию и добавлению тестов
