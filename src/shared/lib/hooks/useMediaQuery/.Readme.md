📱 useMediaQuery — React Hook для медиа-запросов
Простой, производительный и типизированный React-хук для отслеживания состояния CSS-медиа-запросов (например, ширины экрана, темной темы, ориентации и т.д.).

Использует нативный window.matchMedia API с автоматической подпиской на изменения — без лишних ререндеров и ручного debounce.

✨ Особенности
Значение по умолчанию: если вызвать без аргументов — применяется (max-width: 768px).
Поддерживает любые медиа-запросы: max-width, min-width, prefers-color-scheme, orientation, prefers-reduced-motion и др.
Автоматически обрабатывает SSR (не ломается на сервере).
Оптимизирован: реагирует только когда состояние запроса меняется.
Удобный синтаксис: передавайте число для быстрого max-width, или строку для полного контроля.
Написан на TypeScript.
🚀 Использование

1. Базовое использование (произвольный медиа-запрос)

import { useMediaQuery } from '@/shared/lib/hooks/useMediaQuery/useMediaQuery';

function MyComponent() {
const isDarkMode = useMediaQuery('(prefers-color-scheme: dark)');
const isLandscape = useMediaQuery('(orientation: landscape)');

return (

<div>
{isDarkMode ? 'Тёмная тема' : 'Светлая тема'}
{isLandscape && 'Альбомная ориентация'}
</div>
);
}

2. Удобный синтаксис для ширины экрана
   Если вы передаёте число, хук автоматически интерпретирует его как (max-width: ${value}px):
   const isMobile = useMediaQuery(); // ⇨ '(max-width: 768px)' — значение по умолчанию
   const isMobileSmall = useMediaQuery(640); // ⇨ '(max-width: 640px)'
   const isTablet = useMediaQuery(1024); // ⇨ '(max-width: 1024px)'

3. Использование min-width и сложных условий
   Для всего остального — передавайте строку вручную:

const isDesktop = useMediaQuery('(min-width: 1025px)');
const isMediumScreen = useMediaQuery('(min-width: 768px) and (max-width: 1240px)');

🔧 Поддерживаемые типы входных данных
Тип входного параметра | Интерпретация
отсутствует | (max-width: 768px) (значение по умолчанию)
number | (max-width: ${value}px)
string | Любой валидный CSS-медиа-запрос

Примеры:
useMediaQuery();                           // ⇨ (max-width: 768px)
useMediaQuery(640);                        // ⇨ (max-width: 640px)
useMediaQuery('(min-width: 768px)');       // ⇨ min-width: 768px
useMediaQuery('(480px <= width <= 1024px)'); // ⇨ диапазон (поддерживается в новых браузерах)
useMediaQuery('(prefers-reduced-motion: reduce)');

⚙️ Как это работает?
Хук создаёт MediaQueryList через window.matchMedia(query).
При монтировании сразу проверяет текущее состояние (matches).
Подписывается на событие 'change', которое браузер вызывает только при изменении результата запроса.
При размонтировании — корректно отписывается.
На сервере (typeof window === 'undefined') возвращает false и не пытается использовать DOM.
💡 Это лучше, чем отслеживать window.resize, потому что:

Не вызывает лишних обновлений.
Работает с любыми медиа-условиями, а не только с размерами окна.
Использует нативные, оптимизированные механизмы браузера.
📝 Пример: адаптивный компонент

function ResponsiveLayout() {
  const isMobile = useMediaQuery();                 // max-width: 768px
  const isDesktop = useMediaQuery('(min-width: 1025px)');

  if (isMobile) return <MobileView />;
  if (isDesktop) return <DesktopView />;
  return <TableView />;
}
