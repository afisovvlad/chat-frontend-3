Описание
Хук useFileUpload предоставляет удобный и типобезопасный способ загрузки файлов на сервер с:
✅ Встроенной валидацией файлов
✅ Автоматическим управлением состоянием загрузки
✅ Обработкой ошибок
✅ Извлечением данных из ответа сервера
✅ Поддержкой кастомных сообщений об ошибках
✅ Полной типизацией TypeScript

## Установка

## Хук уже встроен в проект. Просто импортируйте его:

Быстрый старт

try {

console.log('Файл успешно загружен!');
} catch (err) {
// Ошибка уже обработана хуком

}
};

return (

<div>
<input type="file" onChange={handleFileChange} disabled={isUploading} />
{error && <div className="error">{error}</div>}
</div>
);
};

## API

## Параметры конфигурации

interface FileUploadConfig<T = unknown> {
/\*\*

- Обязательная функция загрузки файла на сервер
- @param file - файл для загрузки
- @returns Promise с ответом сервера
  \*/
  uploadFn: (file: File) => Promise<T>;

/\*\*

- Опциональная функция валидации файла
- @param file - файл для валидации
- @returns { valid: boolean, error?: string }
  \*/
  validateFn?: (file: File) => Promise<{ valid: boolean; error?: string }>;

/\*\*

- Опциональная функция извлечения данных из ответа
- @param response - ответ от сервера
- @returns извлеченные данные
  \*/
  extractData?: (response: T) => any;

/\*\*

- Опциональные сообщения об ошибках
  \*/
  errorMessages?: {
  validationFailed?: string; // Ошибка валидации
  uploadFailed?: string; // Ошибка загрузки
  extractFailed?: string; // Ошибка извлечения данных
  };
  }

## Возвращаемые значения

interface UseFileUploadResult<T = unknown> {
/\*\*

- Функция загрузки файла
- @param file - файл для загрузки
- @returns Promise с ответом сервера
  \*/
  upload: (file: File) => Promise<T>;

/\*\*

- Статус загрузки (true - идет загрузка)
  \*/
  isUploading: boolean;

/\*\*

- Сообщение об ошибке или null
  \*/
  error: string | null;

/\*\*

- Функция для очистки ошибки
  \*/
  clearError: () => void;

/\*\*

- Последний успешный результат (из extractData или полный ответ)
  \*/
  lastResult: any | null;
  }

1. Загрузка аватара

import { useFileUpload } from '@/shared/lib/hooks/useFileUpload/useFileUpload';

isUploading,

extractFailed: 'Ошибка получения ссылки на аватар'
}

const handleFileChange = async (e: React.ChangeEvent<HTMLInputElement>) => {

if (file) {

await upload(file);

        type="file"

5. Создание специализированного хука

// hooks/useAvatarUpload.ts
import { useCallback } from 'react';
import { useFileUpload } from '@/shared/lib/hooks/useFileUpload/useFileUpload';
import { uploadAvatar } from '@/api/uploadAvatar';
import { validateImageFile } from '@/utils/validateImageFile';

export const useAvatarUpload = (onSuccess?: () => void) => {
const { upload: uploadFile, ...rest } = useFileUpload({
uploadFn: uploadAvatar,
validateFn: validateImageFile,
extractData: (response) => response.file_url,
errorMessages: {
validationFailed: 'Неверный формат аватара',
uploadFailed: 'Не удалось загрузить аватар',
extractFailed: 'Ошибка получения ссылки'
}
});

const upload = useCallback(
async (file: File) => {
await uploadFile(file);
onSuccess?.();
},
[uploadFile, onSuccess]
);

return { upload, ...rest };
};

// Использование
const AvatarComponent = () => {
const { upload, isUploading, error } = useAvatarUpload(() => {
console.log('Аватар успешно загружен!');
});

// ... остальной код
};

## Лучшие практики

✅ Рекомендуется
Всегда используйте валидацию для изображений

validateFn: validateImageFile

Извлекайте только нужные данные

extractData: (response) => response.file_url

Очищайте ошибки после отображения

useEffect(() => {
if (error) {
const timer = setTimeout(() => clearError(), 5000);
return () => clearTimeout(timer);
}
}, [error, clearError]);

Создавайте специализированные хуки для часто используемых сценариев

export const useAvatarUpload = () => { ... }
export const useDocumentUpload = () => { ... }

Используйте кастомные сообщения об ошибках для лучшего UX

errorMessages: {
validationFailed: 'Изображение должно быть в формате JPG или PNG',
uploadFailed: 'Не удалось загрузить фото. Проверьте соединение с интернетом'
}

Не передавайте inline функции в uploadFn

// Плохо - вызовет лишние ререндеры
uploadFn: async (file) => { ... }

// Хорошо - вынесите в отдельную функцию
uploadFn: uploadFile

Не игнорируйте ошибки

// Плохо
await upload(file).catch(() => {});

// Хорошо
try {
await upload(file);
} catch (err) {
// Обработайте ошибку
}

Не используйте lastResult без проверки

// Плохо
<img src={lastResult} />

// Хорошо
{lastResult && <img src={lastResult} />}

## Распространенные ошибки

Ошибка: "Function not implemented"
Проблема: Заглушка функции без реализации.
Решение: Убедитесь, что все функции импортированы правильно:

import { validateImageFile } from '@/utils/validateImageFile';

Ошибка: "Не удалось извлечь данные из ответа"
Проблема: extractData возвращает undefined или null.
Решение: Проверьте структуру ответа сервера:

extractData: (response) => {
console.log('Response:', response); // Отладка
return response.file_url; // Убедитесь, что поле существует
}

Ошибка: "Ошибка валидации файла"
Проблема: Файл не прошел валидацию.
Решение: Проверьте параметры файла и настройки валидации:

validateFn: async (file) => {
console.log('File:', file.type, file.size); // Отладка
// Проверьте логику валидации
}

Проблема: Бесконечные ререндеры
Проблема: Хук вызывается с новыми функциями на каждом ререндере.
Решение: Вынесите функции за пределы компонента или используйте useCallback:

const uploadFn = useCallback(async (file) => { ... }, []);
const { upload } = useFileUpload({ uploadFn });
