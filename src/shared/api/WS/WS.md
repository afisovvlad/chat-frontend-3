что делает каждая функция и переменная в socketClient.ts?

Переменные:

1. soket - хранит ws
2. subscribers - хранит список cb (функций-обработчиков) для каждого action
3. pendingRequests - хранит Promise resolve функции для конкретных запросов sendWS (список запросов на ws)

4. getAccessToken - делает запрос на прокси роут next.js, получаем accessToken

5. createSocket - создаем новый ws, но если уже ws уже есть в переменной socket, то мы не создаем новый, а возвращаем уже существующий

6. setupGlobalMessageHandler - назначает глобальный обработчик onmessage на ws, в этом обработчике происходит:

- проверка на уже существующий обработчик onmessage - если обработчик уже есть -> просто выходим из функции, если нет -> устанавливаем обработчик

- в обработчике onmessage: 1. парсим данные
