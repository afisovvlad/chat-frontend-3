🧩 Базовое использование
Простой текст
<Text>Обычный текст абзаца</Text>

Заголовок (автоматически <h3>)
<Text type={TextType.TITLE}>Заголовок страницы</Text>

🔹 type={TextType.TITLE} → класс text_title (font-size: var(--font-size-24), font-weight: 600, color: var(--foreground-primary)).
🔸 type={TextType.TEXT} → text_text (16px, 400, var(--foreground-secondary)).

⚙️ Пропсы (Props)
Компонент Text принимает следующие пропсы:

# Основные

type — тип текста:
TextType.TITLE — заголовок (по умолчанию рендерится как <h3>);
TextType.TEXT — обычный текст (по умолчанию <p>).
По умолчанию: TextType.TEXT.
children — контент (текст или JSX). Обязательный.

# Стилизация

color — цвет текста. Принимает значения из TextColor:
ERROR, ACCENT, BLACK, GRAY, WHITE.
fontSize — размер шрифта. Используйте TextSize:
S (14px), M (16px), L (18px), XL (24px), XXL (32px), XXXL (34px).
fontWeight — жирность шрифта. Доступные варианты в FontWeight:
REGULAR (400), MEDIUM (500), SEMI_BOLD (600), BOLD (700), EXTRA_BOLD (800).
textAlign — выравнивание текста (TextAlign):
LEFT, CENTER, RIGHT, JUSTIFY.
uppercase — если true, текст отображается в ВЕРХНЕМ регистре.
По умолчанию: false.

# Обрезка текста

truncate — обрезать текст в одну строку с многоточием (...).
По умолчанию: false.
maxLines — ограничить текст 2 или 3 строками. Принимает:
TextClamp.LINES_2 или TextClamp.LINES_3.
⚠️ truncate и maxLines — взаимоисключающие. Приоритет у truncate.

# Семантика и прочее

tag — HTML-тег. Значение зависит от type:
для TITLE — только заголовки: TitleTag.H1, H2, H3, H4;
для TEXT — только текстовые теги: TextTag.P, SPAN, DIV.
По умолчанию: h3 (для заголовков), p (для текста).
margin — внешний отступ (например, "0 0 16px").
lineHeight — межстрочный интервал (например, "1.5" или "24px").
className — дополнительные CSS-классы.
⚠️ Важно!

Для type={TextType.TITLE} → tag принимает только TitleTag (H1, H2, H3, H4).
Для type={TextType.TEXT} → tag принимает только TextTag (P, SPAN, DIV).
Неверная комбинация → ошибка TypeScript на этапе разработки.

🎨 Цвета (TextColor)
Все цвета берутся из дизайн-системы через CSS-переменные. Используйте enum TextColor:

TextColor.BLACK → var(--color-black) — основной цвет заголовков (#1c1c1e);
TextColor.GRAY → var(--color-gray-500) — цвет обычного текста (#747474);
TextColor.ERROR → var(--color-red) — для ошибок (#f00);
TextColor.ACCENT → var(--color-violet-500) — для выделения и акцентирования текста(#7769e1);
TextColor.WHITE → var(--white-color) — белый текст (#fff).

🏷 Семантические теги — правила использования

Заголовки (type={TextType.TITLE})
<Text type={TextType.TITLE} tag={TitleTag.H1}>Главный заголовок</Text>
<Text type={TextType.TITLE} tag={TitleTag.H2}>Подзаголовок</Text>

Текст (type={TextType.TEXT} или без type)
<Text tag={TextTag.P}>Абзац</Text>
<Text tag={TextTag.SPAN}>Встроенный текст</Text>
<Text tag={TextTag.DIV}>Блочный контейнер</Text>

❌ Нельзя:
<Text type={TextType.TITLE} tag={TextTag.SPAN} /> // TS Error!
<Text tag={TitleTag.H1} /> // TS Error! (не указан type=TITLE)

✂️ Обрезка текста
Однострочная (truncate)
<Text truncate>Очень длинный текст...</Text>

Не переносится на новую строку;
Обрезается с ...;
Требует ограниченной ширины контейнера.

Многострочная (maxLines)
<Text maxLines={TextClamp.LINES_2}>Длинный текст...</Text>

Только 2 или 3 строки;
Использует CSS-классы clamp-2 / clamp-3;
Требует ограниченной ширины.
💡 Совет: для URL или длинных слов добавьте в родительский контейнер:
word-break: break-word;

🎨 Цвета и типографика через enum'ы
Цвета
<Text color={TextColor.ERROR}>Ошибка!</Text>
<Text color={TextColor.ACCENT}>Не приходит код?</Text>

Размеры, вес, выравнивание
<Text fontSize={TextSize.XXL} fontWeight={FontWeight.SEMI_BOLD}>
Большой заголовок
</Text>

<Text textAlign={TextAlign.CENTER}>
  Текст по центру
</Text>

📐 Рекомендации
✅ Делайте так:

Используйте type для стандартных стилей.
Кастомизируйте через enum'ы, а не строки или хардкод.

Указывайте семантический tag:
TitleTag.H1–H4 — только с type={TextType.TITLE};

TextTag.P/SPAN/DIV — только с текстом.
Оборачивайте в контейнер с width при truncate/maxLines.

❌ Не делайте так:
Не передавайте color="#f00" — используйте TextColor.ERROR.
Не используйте maxLines без ограничения ширины.
Не задавайте line-height в em без тестирования — может сломать clamp.

🧩 Технические детали
Стили: базовые — через CSS-классы (text_title, text_truncate, clamp-\*); динамические — через style.
Типизация: строгая проверка семантики на этапе компиляции.
Поддержка браузеров: -webkit-line-clamp работает в Chrome, Firefox 68+, Safari, Edge.
Производительность: минимум инлайн-стилей → оптимально для ререндеров.
