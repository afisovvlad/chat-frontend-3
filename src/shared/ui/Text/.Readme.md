📝 Компонент Text
Универсальный, типографически корректный и гибкий компонент для отображения текста в приложении: заголовков, описаний, подписей, ошибок и других текстовых блоков.

Поддерживает:

Автоматические стили для заголовков и обычного текста;
Кастомизацию цвета, размера, веса, выравнивания и отступов;
Обрезку текста:
в одну строку (truncate),
или на 2/3 строки (maxLines).
Совместим с дизайн-системой из Figma через CSS-переменные.

📦 Установка и импорт
Компонент находится в общей библиотеке UI:
import { Text, TextType } from '@/shared/ui/Text';
🧩 Базовое использование

Простой текст
<Text>Обычный текст абзаца</Text>

Заголовок
<Text type={TextType.TITLE}>Заголовок страницы</Text>

truncate и maxLines — взаимоисключающие. Если задан truncate, maxLines игнорируется.
Все стили, кроме truncate и maxLines, применяются как инлайн-стили.

Верхний регистр
Если нужен текст в верхнем регистре, то надо добавить пропс 'uppercase'.

  <Text type={TextType.TITLE} uppercase>
  Заголовок новости		
	</Text>

✂️ Обрезка текста

1. Однострочная (truncate)
   <Text truncate>
   Очень длинный заголовок, который не должен переноситься и должен обрезаться...
   </Text>

   Текст не переносится на новую строку.
   Обрезается с ... справа.
   Требует, чтобы родительский контейнер имел ограниченную ширину.

2. Многострочная (maxLines)

<Text maxLines={2}>
  Этот текст займёт максимум две строки. Всё, что не поместится — скроется...
</Text>

Поддерживает только 2 или 3 строки.
Работает через CSS-классы (clamp-2, clamp-3).
Также требует ограниченной ширины контейнера.
💡 Совет: если текст содержит длинные слова без пробелов (например, URL), добавь word-break: break-word в родительский контейнер или кастомный класс.

🎨 Цвета из дизайн-системы
В проекте используются CSS-переменные, определённые в :root. Используй их для согласованности:

# Ошибка (красный)

<Text color="var(--color-red)">Произошла ошибка</Text>

# Предупреждение (фиолетовый)

<Text color="var(--color-violet-500)">Внимание: действие нельзя отменить</Text>

# Заголовок (чёрный)

<Text type={TextType.TITLE} color="var(--color-black)">
Важная информация
</Text>

🧪 Примеры
Заголовок с выравниванием и обрезкой

<Text
type={TextType.TITLE}
textAlign="center"
maxLines={2}
tag="h2"

> Длинный заголовок новости, центрированный и ограниченный двумя строками
> </Text>

# Подпись под картинкой

<Text
fontSize="var(--font-size-14)"
color="var(--foreground-secondary)"
textAlign="center"
margin="8px 0 0"> Подпись под картинкой. 2025 </Text>

# Ошибка в форме

<Text color="var(--color-red)" fontSize="14px" margin="4px 0 0">
  Поле обязательно для заполнения
</Text>

📐 Рекомендации по использованию
✅ Делайте так:
Используйте type для стандартных случаев (title / text).
Передавайте цвета через var(--...), а не хардкодьте #1c1c1e.
Указывайте семантический tag:
h1–h4 — для заголовков,
p — для абзацев,
span — для строчных фрагментов.
Оборачивайте Text в контейнер с фиксированной или ограниченной шириной, если используете truncate или maxLines.
❌ Не делайте так:
Не передавайте undefined в пропсы (но компонент это корректно обрабатывает).
Не используйте maxLines без ограничения ширины — обрезка не сработает.
Не задавайте line-height в em без расчёта — это может сломать maxLines.
🧩 Технические детали
Реализация обрезки:
truncate → инлайн-стили (whiteSpace: nowrap и др.)
maxLines → SCSS-классы с -webkit-line-clamp (требуется CSS-правило).
Поддержка браузеров:
-webkit-line-clamp работает во всех современных браузерах (Chrome, Firefox 68+, Safari, Edge).
Производительность:
Инлайн-стили — приемлемы для текста (низкая частота ререндеров).
