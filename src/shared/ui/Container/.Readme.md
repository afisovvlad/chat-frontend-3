# Универсальный layout-компонент для построения структуры страниц в проекте. Поддерживает несколько режимов отображения через тип ContainerType, позволяя создавать как глобальные обёртки, так и гибкие многоколоночные интерфейсы.

# Доступные типы

# MAIN (по умолчанию)

Основной контейнер страницы:
Центрирует содержимое по горизонтали.
Ограничивает максимальную ширину (max-width: 1200px).
Занимает всю высоту вьюпорта (height: 100dvh).
Добавляет адаптивные горизонтальные отступы.
Используется в корневом layout'е приложения.

# SIDEBAR

Второстепенная панель (например, список чатов или навигация):
Фиксированная ширина 360px на десктопе.
Фон задаётся через CSS-переменную --cont-bg-sidebar.
Поддерживает внутренний вертикальный скролл.
На мобильных устройствах (≤768px) растягивается на всю ширину.

# CONTENT

Основная область контента (например, окно чата):
Фиксированная ширина 744px на десктопе.
Фон из переменной --cont-bg-content.
Имеет внутренний скролл.
На мобильных — скрывается по умолчанию (display: none), это заглушка для разработки — в финальной версии поведение должно управляться логикой приложения (например, показ/скрытие в зависимости от выбранного чата).

# WRAPPER

Гибкая layout-обёртка для размещения нескольких областей:
Использует display: flex с gap: 24px.
На десктопе — располагает дочерние элементы в ряд.
На мобильных (≤768px) — переключается в колонку и убирает gap.
Занимает 100% высоты и ширины родителя.
Предназначен для объединения SIDEBAR и CONTENT в единую раскладку.

# Как использовать

Пример: страница чатов

<Container type={ContainerType.WRAPPER}>
  <Container type={ContainerType.SIDEBAR}>
    <ChatList />
  </Container>
  <Container type={ContainerType.CONTENT}>
    <ChatWindow />
  </Container>
</Container>

Пример: глобальный layout

<Container>
  <Header />
  <main>{children}</main>
</Container>

# Особенности и рекомендации

Все типы, кроме WRAPPER, наследуют базовые стили .container (высота, центрирование, отступы).
WRAPPER — полностью независимый layout-контейнер, не использует max-width и margin: auto.
На мобильных устройствах CONTENT по умолчанию скрыт — не забудьте заменить display: none на логику показа в финальной реализации.
Для кастомизации можно передавать дополнительный className.

# Адаптивность

Компонент полностью адаптивен:
Десктоп (>768px): WRAPPER → горизонтальная раскладка.
Мобильный (≤768px): WRAPPER → вертикальная раскладка, SIDEBAR и CONTENT — на всю ширину.
Отступы автоматически подстраиваются под размер экрана.
