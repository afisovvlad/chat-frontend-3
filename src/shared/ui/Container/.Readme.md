# В проекте реализована система универсальных контейнеров для построения макетов. Все контейнеры используют CSS Modules и поддерживают кастомизацию через пропс className.

# Container

Основной контейнер для глобальной обёртки страницы и формирования колонок интерфейса. Используется в связке с перечислением ContainerTypeEnum.

# Доступные типы:

# MAIN — глобальный контейнер страницы.

Центрирует содержимое, задаёт максимальную ширину (1210px), обеспечивает полноэкранную высоту (100dvh), добавляет горизонтальные отступы. Используется в корневом layout для оборачивания всего приложения.

# LEFT — левая колонка (например, список чатов или навигация).

Фиксированная ширина 360px, фон из переменной --cont-bg-left, автоматический вертикальный скролл при переполнении. На мобильных устройствах (≤768px) растягивается на всю ширину.

# RIGHT — правая колонка (например, область чата или форма редактирования).

Ширина 744px на десктопе, растягивается (flex: 1) для заполнения оставшегося пространства, фон из --cont-bg-right, также поддерживает скролл. На мобильных — ширина 100%.
Особенности:
Все колонки (LEFT, RIGHT) имеют высоту 100dvh и overflow-y: auto, что позволяет им скроллиться независимо.
Адаптивность встроена: на мобильных устройствах ширина колонок становится 100%.
По умолчанию используется тип MAIN.

Пример использования:
<Container type={ContainerTypeEnum.LEFT}>
<ChatList />
</Container>

<Container type={ContainerTypeEnum.RIGHT}>
  <ChatWindow />
</Container>

# FlexContainer

Универсальная обёртка для горизонтального или вертикального расположения дочерних элементов. Предназначена для создания гибких layout-структур внутри страниц (например, двухколоночных секций, форм с сайдбарами и т.д.).

# Особенности:

По умолчанию располагает дочерние элементы в ряд (flex-direction: row) с отступом gap: 24px.
На мобильных устройствах (≤768px) переключается в колонку (flex-direction: column) и убирает gap.
Занимает всю доступную высоту (height: 100%) и ширину (width: 100%).
Блокирует внешний скролл через overflow: hidden — скролл должен управляться внутри дочерних компонентов.
Когда использовать:
Когда нужно разместить два или более блока рядом (например, панель настроек + превью).
Внутри Container типа MAIN или RIGHT, чтобы организовать вложенный layout.
Для любых кастомных раскладок, не попадающих под стандартные LEFT/RIGHT.

Пример использования:
<FlexContainer>
<SettingsSidebar />
<SettingsContent />
</FlexContainer>

# Общие рекомендации

Используйте Container с типами LEFT/RIGHT только для основных колонок приложения (чаты, настройки, профиль).
Для вложенных или временных layout-структур — применяйте FlexContainer.
Оба компонента поддерживают передачу кастомного className для переопределения стилей.
Убедитесь, что родительские элементы (особенно в layout.tsx) корректно передают высоту (flex: 1, min-height: 0), иначе height: 100% может не сработать.
