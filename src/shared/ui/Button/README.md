|Темы
• CLEAR: Прозрачная кнопка без фона.
• OUTLINE: Кнопка с рамкой.
• BACKGROUND: Кнопка с фоновым цветом.
• CIRCLE: Кнопка с круглой формой, подходит для иконок.

ЕСЛИ НУЖНА КНОПКА ПРИ ПОСТУПАЮЩЕМ ЗВОНКЕ (ПРИНЯТЬ / ОТКЛОНИТЬ) УКАЗЫВАЙТЕ ПРОПС - callBtn

▎Размеры

• size_s: Маленький размер, используется в модальных окнах (размер под внутреннее содержимое).
• size_m: Средний размер, используется, когда в одной строчке две кнопки
• size_l: Большой размер, на всю ширину родителя.

|Как работают цвета для разных тем кнопок

• CLEAR - цвет задается для текста.
• OUTLINE: цвет задается для рамки и текста.
• BACKGROUND: цвет задается для фона.
• CIRCLE: цвет задается для фона.
