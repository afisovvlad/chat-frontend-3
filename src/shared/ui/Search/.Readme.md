📖 Компонент поиска

## Описание

Компонент поиска предоставляет гибкую и оптимизированную систему поиска для различных сценариев использования:
✅ Локальный поиск - фильтрация уже загруженных данных
✅ Глобальный поиск - поиск через бэкенд (например, @упоминания)
✅ Минимальные перерендеры благодаря React.memo, useCallback, useMemo
✅ Полная поддержка доступности (a11y)
✅ Горячие клавиши (Escape для очистки)
✅ Дебаунс для оптимизации производительности
✅ Работа со стором через useAppSelector и useAppDispatch
✅ Типобезопасность через дженерики

📦 Установка

// UI компоненты
import { Search, SearchInput } from '@/features/Search';

// Фильтры

## Свойства компонента Search

# value (string) — Обязательный

Текущее значение поля ввода поиска

# onChange ((value: string) => void) — Обязательный

Колбэк, вызываемый при изменении значения поиска

# placeholder (string) — Опциональный (по умолчанию: 'Поиск...')

Текст-подсказка, отображаемый в пустом поле ввода

# className (string) — Опциональный (по умолчанию: '')

Дополнительный CSS-класс для контейнера компонента

# inputClassName (string) — Опциональный (по умолчанию: '')

Дополнительный CSS-класс для элемента <input>

# disableClear (boolean) — Опциональный (по умолчанию: false)

Отключает отображение кнопки очистки поля поиска

# showIcon (boolean) — Опциональный (по умолчанию: true)

Управляет отображением иконки поиска внутри поля

# onClear (() => void) — Опциональный

Колбэк, вызываемый при нажатии кнопки очистки или клавиши Escape

# inputRef (React.Ref<HTMLInputElement>) — Опциональный

Реф для прямого доступа к DOM-элементу <input>

## Хуки

# useLocalSearch Hook

function useLocalSearch<T>(
data: T[],
filterFn: (items: T[], searchTerm: string) => T[],
debounceDelay?: number
): {
searchTerm: string;
filteredData: T[];
handleSearchChange: (value: string) => void;
handleClear: () => void;
}

Возвращает:
searchTerm - текущее значение поиска
filteredData - отфильтрованный массив
handleSearchChange - обработчик изменения поиска
handleClear - обработчик очистки

# useGlobalSearch Hook

function useGlobalSearch<T>(
onSearch: (searchTerm: string) => Promise<T[]>,
debounceDelay?: number
): {
searchTerm: string;
results: T[];
isLoading: boolean;
error: Error | null;
handleSearchChange: (value: string) => void;
handleClear: () => void;
}
Возвращает:
searchTerm - текущее значение поиска
results - результаты поиска
isLoading - состояние загрузки
error - ошибка (если есть)
handleSearchChange - обработчик изменения поиска
handleClear - обработчик очистки

## useHybridSearch Hook

function useHybridSearch<T>(
localData: T[],
localFilterFn: (items: T[], searchTerm: string) => T[],
globalSearchFn: (searchTerm: string) => Promise<T[]>,
debounceDelay?: number,
globalPrefix?: string
): {
searchTerm: string;
results: T[];
isGlobal: boolean;
isLoading: boolean;
error: Error | null;
handleSearchChange: (value: string) => void;
handleClear: () => void;
}

# Параметры:

localData — массив локальных данных для фильтрации
localFilterFn — функция локальной фильтрации
globalSearchFn — функция глобального поиска через бэкенд
debounceDelay — задержка дебаунса (по умолчанию: 300)
globalPrefix — префикс для глобального поиска (по умолчанию: '@')

# Возвращает:

searchTerm — текущее значение поиска
results — результаты поиска (локальные или глобальные)
isGlobal — флаг: является ли поиск глобальным
isLoading — состояние загрузки (для глобального поиска)
error — ошибка (если есть)
handleSearchChange — обработчик изменения поиска
handleClear — обработчик очистки

# Логика работы:

Если строка поиска начинается с @ → глобальный поиск через бэкенд
Если строка поиска не начинается с @ → локальный поиск по массиву

## Сценарии использования

# Когда использовать useLocalSearch?

✅ Поиск по уже загруженным данным
✅ Когда все данные доступны на клиенте
✅ Когда нужна максимальная скорость
✅ Когда не нужно обращаться к бэкенду
Примеры:
Поиск по списку чатов
Поиск по списку контактов (уже загруженных)
Фильтрация сообщений в диалоге

# Когда использовать useGlobalSearch?

✅ Поиск только через бэкенд
✅ Когда данных на клиенте нет
✅ Когда нужен поиск по всей базе данных
✅ Когда нужна пагинация/лимиты
Примеры:
Поиск пользователей по нику
Поиск публичных каналов
Поиск постов в ленте

# Когда использовать useHybridSearch?

✅ Комбинированный поиск (локальный + глобальный)
✅ Когда нужно автоматически определять тип поиска
✅ Когда пользователь может искать как локально, так и глобально
✅ Когда нужен префикс для глобального поиска (например, @)
Примеры:
Поиск контактов: @вася (глобальный), вася (локальный)
Поиск чатов: @публичный (глобальный), личный (локальный)
Универсальный поиск с префиксом

♿ Доступность (a11y)

Компонент полностью поддерживает доступность:
✅ role="search" для контейнера поиска
✅ aria-label для инпута и кнопок
✅ aria-hidden="true" для декоративных иконок
✅ Поддержка клавиши Escape для очистки поиска
✅ type="search" для семантически правильного инпута
✅ autoComplete="off" для отключения автозаполнения
✅ spellCheck={false} для отключения проверки орфографии
