🧩 Компонент Modal
Универсальное модальное окно с поддержкой:

закрытия по Escape, клику вне и кнопке;
произвольного содержимого (children);
гибкой кастомизации через CSS-модули;
нескольких экземпляров на одной странице.
Использует createPortal и полностью совместим с Next.js App Router.

📦 Импорт
import { Modal } from '@/shared/ui/modal/ui/Modal';

✨ Базовое использование

'use client';

import { useState } from 'react';
import { Modal } from '@/shared/ui/Modal/Modal';
import { Button } from '@/shared/ui/Button/Button';
import { Text } from '@/shared/ui/Text/Text';

export default function MyPage() {
const [isOpen, setIsOpen] = useState(false);

return (
<>
<Button onClick={() => setIsOpen(true)}>Открыть</Button>
<Modal
isOpen={isOpen}
onClose={() => setIsOpen(false)}
closeButton // показать кнопку закрытия >
<Text type={TextType.TITLE}>Заголовок</Text>
<Text>Произвольный контент: формы, инпуты, чекбоксы...</Text>

        <Modal.Actions>
          <Button onClick={() => setIsOpen(false)}>Отмена</Button>
          <Button color={ButtonColor.PRIMARY}>Подтвердить</Button>
        </Modal.Actions>
      </Modal>
    </>

);
}

🎨 Кастомизация через CSS-модули
Компонент использует SCSS-модули, поэтому для стилизации не нужно использовать !important — просто передайте свой класс через className.

Пример: кастомные отступы и ширина

/_ MyPage.module.scss _/
.customModal {
max-width: 320px;
}

.customModal :global(.modal_content) {
padding: 24px 20px;
}

.customModal :global(.modal_actions) {
padding: 0 20px 20px;
}

// MyPage.tsx
<Modal
isOpen={isOpen}
onClose={onClose}
className={styles.customModal} // ← применяется к .modal

> <Text>Контент</Text>
> <Modal.Actions>

    <Button>OK</Button>

</Modal.Actions>
</Modal>

Обрати внимание на :global(.modal_content) —
внутренние классы (content, actions) — локальные, поэтому их нужно глобализировать для переопределения.

🧱 Структура CSS-классов (для переопределения)
Компонент генерирует следующие локальные классы (имена хешируются):

### Пропсы

| Имя           | Тип                    | Описание                                                                                                |
| ------------- | ---------------------- | ------------------------------------------------------------------------------------------------------- |
| `isOpen`      | `boolean`              | Управляет видимостью модального окна                                                                    |
| `onClose`     | `() => void`           | Вызывается при закрытии (по Escape, клику вне или кнопке)                                               |
| `children`    | `ReactNode`            | Основной контент модалки — может включать текст, формы, кнопки и т.д.
| `closeButton` | `boolean \| ReactNode` | Если `true` — показывается стандартная иконка закрытия. Можно передать свой JSX-элемент (например, SVG) |
| `className`   | `string`               | Дополнительный CSS-класс для кастомизации модального окна                                               |

🧪 Несколько модалок на одной странице
Поддерживается «из коробки». Просто создайте отдельные состояния:

const [isDeleteModalOpen, setIsDeleteModalOpen] = useState(false);
const [isInfoModalOpen, setIsInfoModalOpen] = useState(false);

return (
<>
<Button onClick={() => setIsDeleteModalOpen(true)}>Удалить</Button>
<Button onClick={() => setIsInfoModalOpen(true)}>Инфо</Button>

    <Modal isOpen={isDeleteModalOpen} onClose={() => setIsDeleteModalOpen(false)}>
      {/* ... */}
    </Modal>

    <Modal isOpen={isInfoModalOpen} onClose={() => setIsInfoModalOpen(false)}>
      {/* ... */}
    </Modal>

</>
);

🧩 Подкомпонент Modal.Actions
Используйте для размещения кнопок внизу модалки

//
<Modal.Actions className={styles.myActions}>
<Button>Отмена</Button>
<Button color={ButtonColor.DANGER}>Удалить</Button>
</Modal.Actions>
//

Modal.Actions — это просто <div class="actions">, стилизуемый через className.

🔐 Доступность (a11y)
Закрытие по Escape;
Остановка прокрутки фона;
Фокус остаётся внутри модалки (рекомендуется добавить focus trap для продакшена).
❗ Ограничения
Работает только в клиентских компонентах ('use client');
Не совместим с SSR — но в Next.js это нормально (рендерится только на клиенте).
