🧩 Компонент Modal
Универсальное модальное окно с поддержкой:

закрытия по Escape, клику вне области и кнопке;
произвольного содержимого (children);
семантических размеров (compact, mobileNarrow и др.);
гибкой кастомизации через CSS-модули;
нескольких экземпляров на одной странице;
базовой доступности (a11y): role="dialog", aria-modal, управление overflow, фокус при открытии.
Использует createPortal и полностью совместим с Next.js App Router (требуется 'use client').4

📦 Импорт
import { Modal } from '@/shared/ui/modal/ui/Modal';

✨ Базовое использование

'use client';

import { useState } from 'react';
import { Modal } from '@/shared/ui/Modal/Modal';
import { Button } from '@/shared/ui/Button/Button';
import { Text } from '@/shared/ui/Text/Text';

export default function MyPage() {
const [isOpen, setIsOpen] = useState(false);

return (
<>
<Button onClick={() => setIsOpen(true)}>Открыть</Button>

      <Modal
        isOpen={isOpen}
        onClose={() => setIsOpen(false)}
        closeButton
        size="compact" // ← новый пропс!
      >
        <Text type={TextType.TITLE}>Заголовок</Text>
        <Text>Произвольный контент: формы, инпуты, чекбоксы...</Text>

        <Modal.Actions>
          <Button onClick={() => setIsOpen(false)}>Отмена</Button>
          <Button color={ButtonColor.PRIMARY}>Подтвердить</Button>
        </Modal.Actions>
      </Modal>
    </>

);
}

### 📏 Поддерживаемые размеры (`size`)

Размеры модального окна строго соответствуют дизайн-системе проекта и задаются **семантически** через пропс `size`.  
Нельзя передать произвольное значение — только из предопределённого списка.

| Значение       | Ширина | Контекст использования |
| -------------- | ------ | ---------------------- |
| `compact`      | 280px  | Мини-модалки (desktop) |
| `regular`      | 360px  | Стандартные формы      |
| `wide`         | 400px  | Расширенный контент    |
| `extraWide`    | 432px  | Широкие формы          |
| `mobileNarrow` | 329px  | Мобильные устройства   |
| `mobileWide`   | 361px  | Мобильные устройства   |

> 💡 Все размеры централизованы в файле [`shared/config/modalSizes.ts`](./shared/config/modalSizes.ts).

Пример:
<Modal isOpen={isOpen} size="mobileWide" onClose={onClose} />

🎨 Кастомизация через CSS-модули
Компонент использует SCSS Modules, поэтому для стилизации не нужно !important — просто передайте свой класс через className.

Пример: кастомные отступы и ширина

/_ MyPage.module.scss _/
.customModal {
max-width: 320px;
}

.customModal :global(.content) {
padding: 24px 20px;
}

.customModal :global(.actions) {
padding: 0 20px 20px;
}

<Modal
isOpen={isOpen}
onClose={onClose}
className={styles.customModal}

> <Text>Контент</Text>
> <Modal.Actions>

    <Button>OK</Button>

</Modal.Actions>
</Modal>

Обрати внимание на :global(.content) и :global(.actions) — внутренние классы локальные, поэтому их нужно глобализировать для переопределения.

| Элемент          | Локальный класс в SCSS | Использование в `:global()`       |
| ---------------- | ---------------------- | --------------------------------- |
| Обёртка модалки  | `.modal`               | — (стилизуется через `className`) |
| Контент          | `.content`             | `:global(.content)`               |
| Кнопки (Actions) | `.actions`             | `:global(.actions)`               |
| Кнопка закрытия  | `.closeButton`         | `:global(.closeButton)`           |

🧱 Структура внутренних CSS-классов (для :global)

📥 Пропсы
isOpen (boolean)
Управляет видимостью модального окна.
onClose (() => void)
Вызывается при закрытии (по нажатию Escape, клику вне модального окна или по кнопке закрытия).
children (ReactNode)
Основной контент модалки: текст, формы, инпуты и другие React-элементы.
closeButton (boolean | ReactNode)
Определяет отображение кнопки закрытия:
если true — показывается стандартная иконка закрытия;
если передан ReactNode (например, кастомный SVG) — используется он;
если false или проп не передан — кнопка не отображается.
className (string)
Дополнительный CSS-класс, применяемый к корневому элементу модалки (.modal). Используется для кастомной стилизации через SCSS-модули.
size (ModalSize)
Предустановленный размер модального окна. Возможные значения:
compact, regular, wide, extraWide, mobileNarrow, mobileWide
(см. таблицу размеров). |

const [isInfoModalOpen, setIsInfoModalOpen] = useState(false);

return (
<>
<Button onClick={() => setIsDeleteModalOpen(true)}>Удалить</Button>
<Button onClick={() => setIsInfoModalOpen(true)}>Инфо</Button>

    <Modal isOpen={isDeleteModalOpen} onClose={() => setIsDeleteModalOpen(false)} size="compact">
      {/* ... */}
    </Modal>

    <Modal isOpen={isInfoModalOpen} onClose={() => setIsInfoModalOpen(false)} size="regular">
      {/* ... */}
    </Modal>

</>
);
🧩 Подкомпонент Modal.Actions
Используется для размещения кнопок внизу модалки:

<Modal.Actions className={styles.myActions}>
<Button>Отмена</Button>
<Button color={ButtonColor.DANGER}>Удалить</Button>
</Modal.Actions>

Это просто <div class="actions"> — стилизуется через className или :global(.actions).

🔍 Важно: стили фокуса для интерактивных элементов
Проект использует CSS-сброс (reset), который обнуляет стандартные стили фокуса (outline) у всех интерактивных элементов, включая кнопки.

Чтобы обеспечить доступность и навигацию с клавиатуры, все кнопки, передаваемые внутрь модального окна (в том числе через <Modal.Actions>), должны явно определять визуальный индикатор фокуса, например:

.myButton {
// ...

&:focus-visible {
outline: 2px solid var(--color-focus);
outline-offset: 2px;
border-radius: 6px;
}
}

💡 Рекомендуется использовать псевдокласс :focus-visible, а не :focus, чтобы показывать индикатор только при клавиатурной навигации, сохраняя чистый вид при клике мышью.

Без этого пользователи, полагающиеся на клавиатуру или скринридеры, не смогут определить, какой элемент активен — это нарушает требования WCAG и ухудшает UX.

🔐 Доступность (a11y)
✅ Закрытие по Escape
✅ Блокировка прокрутки фона (overflow: hidden)
✅ Восстановление исходного overflow при закрытии
✅ role="dialog", aria-modal="true"
✅ Фокус устанавливается внутрь модалки при открытии (tabIndex={-1} + .focus())
⚠️ Для продакшена рекомендуется добавить focus trap (например, через react-focus-lock)

❗ Ограничения
Работает только в клиентских компонентах ('use client')
Не рендерится на сервере — но это нормально для модалок в Next.js
