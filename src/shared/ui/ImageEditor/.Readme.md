📷 ImageEditor & AvatarUploader — компоненты для загрузки и кадрирования аватара
Набор переиспользуемых React-компонентов для загрузки изображения, его предварительного просмотра и точной настройки области отображения (cropping) с поддержкой desktop и mobile.

🧩 Состав пакета

ImageEditor — модальное окно с интерфейсом кадрирования изображения (на базе react-avatar-editor).
AvatarUploader — обёртка, управляющая открытием редактора и выбором файла.
useImageEditorConfig — хук для адаптивного определения размеров аватара (320×320 на desktop, 193×193 на mobile).
useMediaQuery — утилитный хук для реакции на CSS-медиа-запросы с поддержкой SSR и автоматической очисткой подписок

📦 Установка зависимостей
Убедитесь, что установлены:

## npm install react-avatar-editor focus-trap-react

**Компоненты используют ваши внутренние UI-библиотеки: Button, Text, иконки (Close, Checked), SCSS-модули.**

🧠 Основные возможности
✅ Загрузка изображения через файловый диалог
✅ Интерактивное кадрирование с масштабированием
✅ Поддержка Retina-дисплеев (disableHiDPIScaling={false})
✅ Адаптивный дизайн:
Desktop: подтверждение через кнопку-галочку в модалке
Mobile: подтверждение через фиксированный footer
✅ Полная доступность (a11y): клавиатура, ARIA, фокус-трэп
✅ TypeScript-типы и imperative handle API
✅ Изоляция стилей через CSS Modules
🧪 Использование

1. Подключение компонента

import { AvatarUploader, AvatarUploaderRef } from '@/shared/ui/AvatarUploader';
import { useState, useRef } from 'react';

const ProfilePage = () => {
const [avatar, setAvatar] = useState<string | null>(null);
const avatarRef = useRef<AvatarUploaderRef>(null);

    const handleAvatarChange = (dataUrl: string) => {
    	setAvatar(dataUrl); // base64-строка изображения
    };

    return (
    	<form>
    		<Button onClick={() => avatarRef.current?.openFilePicker()}>
    			Изменить аватар
    		</Button>

    		<AvatarUploader
    			ref={avatarRef}
    			onAvatarChange={handleAvatarChange}
    			initialAvatar={avatar}
    		/>

    		<Button type="submit">Сохранить профиль</Button>
    	</form>
    );};

2. Imperative API (через ref)
   Компонент AvatarUploader предоставляет методы:

interface AvatarUploaderRef {
openFilePicker: () => void; // открыть системный выбор файла
close: () => void; // закрыть редактор (если открыт)
}

Пример:

## avatarRef.current?.openFilePicker(); // вызвать выбор файла программно

🔧 Внутренние компоненты
ImageEditor (внутренний, используется через AvatarUploader)

## Props:

interface ImageEditorProps {
onOpen?: () => void; // вызывается при открытии модалки
onClose?: () => void; // вызывается при закрытии
onConfirm?: (dataUrl: string) => void; // вызывается при подтверждении (base64)
}

## Imperative Handle (ref):

interface ImageEditorRef {
open: () => void; // открыть модалку
close: () => void; // закрыть модалку
getResult: () => Promise<string | null>; // получить base64 вручную
setImage: (url: string) => void; // установить изображение
confirm: () => Promise<void>; // подтвердить выбор (вызовет onConfirm)
}
⚠️ Обычно вы не используете ImageEditor напрямую — только через AvatarUploader.

📐 Кастомные хуки

## useImageEditorConfig()

Назначение:

Возвращает конфигурацию размеров аватара в зависимости от ширины экрана.
Возвращаемое значение:
{
width: number; // 320 на desktop, 193 на mobile
height: number; // = width
borderRadius: number; // = width / 2 (круглая форма)
}

Используется внутри ImageEditor автоматически.

useMediaQuery(query: string)
Назначение:
Реагирует на CSS-медиа-запросы в JavaScript.

Пример:
const isMobile = useMediaQuery('(max-width: 767px)');
const isDesktop = useMediaQuery('(min-width: 768px)');

Особенности:

Безопасен для SSR (проверяет typeof window)
Автоматически подписывается/отписывается от изменений
Оптимизирован через useEffect и мемоизацию
🎨 Стилизация
Компоненты используют CSS Modules. Основные классы:

.overlay — затемнение фона
.modalContent — контейнер модалки
.editorWrapper — область редактора
.mobileFooter — кнопки на мобильных устройствах (фиксированный снизу)
Убедитесь, что в вашем AvatarUploader.module.scss есть стили для .mobileFooter с position: fixed.

♿ Доступность (Accessibility)
Модалка имеет role="dialog" и aria-modal="true"
Фокус ловится внутри модалки (focus-trap-react)
Все интерактивные элементы имеют aria-label
Поддержка управления с клавиатуры (Escape для закрытия)
Семантические теги (<button>, а не <div>)
💾 Формат изображения
Результат всегда возвращается как base64-строка JPEG с качеством 85%:

**canvas.toDataURL('image/jpeg', 0.85)**

Это оптимально для аватаров (меньше размер, чем PNG, без прозрачности).

✨ Совет: Перед отправкой на бэкенд обрежьте префикс data:image/jpeg;base64,, если сервер ожидает чистый base64.
