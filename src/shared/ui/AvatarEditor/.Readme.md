📷 ImageEditor & AvatarUploader — компоненты для загрузки и кадрирования аватара
Набор переиспользуемых React-компонентов для загрузки изображения, его предварительного просмотра и точной настройки области отображения (cropping) с поддержкой desktop и mobile.
Полностью кастомная реализация на основе <canvas>, без сторонних библиотек редактирования.

🧩 Состав пакета

# AvatarUploader — обёртка, управляющая открытием редактора, выбором файла и обработкой ошибок.

# ImageEditor — модальное окно с интерфейсом кадрирования (drag + zoom).

# CustomAvatarEditor — низкоуровневый canvas-редактор с поддержкой масштабирования, перетаскивания и круговой маски.

# useImageEditorConfig — хук для адаптивного определения размеров аватара (320×320 на desktop, 193×193 на mobile).

# useMediaQuery — утилитный хук для реакции на CSS-медиа-запросы с поддержкой SSR.

🧠 Основные возможности
✅ Загрузка изображения через файловый диалог (поддержка JPEG/PNG, ограничение 5 МБ)
✅ Интерактивное кадрирование:
 - Drag & drop для перемещения изображения
 - Ползунок масштабирования (zoom)
 - Круговая маска (аватар всегда круглый)
✅ Поддержка Retina-дисплеев (devicePixelRatio)
✅ Адаптивный дизайн:
 - Desktop: подтверждение через кнопку-галочку в модалке
 - Mobile: подтверждение через фиксированный footer (position: fixed)
✅ Полная доступность (a11y):
 - Фокус-трэп внутри модалки (focus-trap-react)
 - Закрытие по Escape
 - ARIA-атрибуты (role="dialog", aria-modal="true")
✅ TypeScript-типы и imperative handle API
✅ Изоляция стилей через CSS Modules

🧪 Использование

1. Подключение компонента

import { AvatarUploader, AvatarUploaderRef } from '@/shared/ui/AvatarUploader';
import { useState, useRef } from 'react';

const ProfilePage = () => {
const [avatar, setAvatar] = useState<string | null>(null);
const avatarRef = useRef<AvatarUploaderRef>(null);

const handleAvatarChange = (dataUrl: string) => {
setAvatar(dataUrl); // base64-строка изображения
};

return (

<form>
<Button onClick={() => avatarRef.current?.openFilePicker()}>
Изменить аватар
</Button>

      <AvatarUploader
        ref={avatarRef}
        onAvatarChange={handleAvatarChange}
        initialAvatar={avatar}
      />

      <Button type="submit">Сохранить профиль</Button>
    </form>

);
};

2. Imperative API (через ref)
   Компонент AvatarUploader предоставляет методы:

interface AvatarUploaderRef {
openFilePicker: () => void; // открыть системный выбор файла
close: () => void; // закрыть редактор (если открыт)
}

Пример: avatarRef.current?.openFilePicker(); // вызвать выбор файла программно

🔧 Внутренние компоненты

ImageEditor (используется через AvatarUploader)

interface ImageEditorProps {

interface ImageEditorRef {

📐 Кастомные хуки
useImageEditorConfig()
Назначение: Возвращает конфигурацию размеров аватара в зависимости от ширины экрана.
Возвращаемое значение:
{
width: number; // 320 на desktop, 193 на mobile
height: number; // = width
borderRadius: number; // = width / 2 (круглая форма)
}

Используется внутри ImageEditor автоматически.
🎨 Стилизация
Компоненты используют CSS Modules. Основные классы:
.overlay — затемнение фона
.modal — контейнер модалки
.editorWrapper — область редактора
.mobileFooter — кнопки на мобильных устройствах (обязательно position: fixed)

♿ Доступность (Accessibility)
Модалка: role="dialog", aria-modal="true"
Фокус ловится внутри (focus-trap-react)
Все кнопки имеют aria-label
Поддержка клавиатуры: Escape → закрыть
Семантические теги (<button>, а не <div>)
💾 Формат изображения
Результат всегда возвращается как base64-строка JPEG с качеством 85%:
canvas.toDataURL('image/jpeg', 0.85)

Это оптимально для аватаров:
Меньше размер, чем PNG
Нет прозрачности (не нужна для круглого аватара)

# Перед отправкой на бэкенд обрежьте префикс data:image/jpeg;base64,, если сервер ожидает чистый base64.
