📱 ChatList

# Назначение

Компонент отображает список чатов с возможностью поиска и фильтрации.

# Принцип работы

Поиск: Фильтрует чаты по имени, никнейму, фамилии, отчеству и тексту последнего сообщения
Отображение: Показывает список чатов или сообщение "Чаты не найдены" при отсутствии результатов
Селекция: Подсвечивает активный чат и передаёт его uid при выборе

# Пропсы

searchQuery (string) — Текущее значение поиска
onSearchChange ((value: string) => void) — Обработчик изменения поиска
onSearchClear (() => void) — Обработчик очистки поиска
onSelectChat ((uid: string) => void) — Обработчик выбора чата
selectedChatUid (string | null) — UID активного чата

# Особенности

✅ Работает с моковыми данными
✅ Поддерживает поиск по всем полям чата
✅ Сохраняет поисковую строку даже при пустых результатах
✅ Полностью доступен (a11y)

📨 ChatListItem

# Назначение

Отдельный элемент списка чатов с информацией о чате и последнем сообщении.

# Принцип работы

Отображение: Показывает аватар, имя чата, последнее сообщение, время и количество непрочитанных сообщений
Интерактивность: Реагирует на клик, hover, focus и active состояния
Состояния: Визуально выделяет активный чат

# Пропсы

chat (Chat) — Объект чата с полной информацией
isActive (boolean) — Флаг активного состояния
onSelect ((uid: string) => void) — Обработчик клика на чат

# Особенности

✅ Показывает избранные чаты (иконка ★)
✅ Отображает количество непрочитанных сообщений
✅ Форматирует время последнего сообщения
✅ Оптимизирован через React.memo
✅ Полностью доступен (a11y)

🌐 ChatsPage

# Назначение

Основная страница приложения для отображения списка чатов и выбранного диалога.

# Принцип работы

Двухколоночная структура: Левая панель — список чатов, правая — содержимое выбранного чата
Взаимодействие: При выборе чата отображается ChatWidget с диалогом
Поиск: Управляет состоянием поиска и передаёт его в ChatList

# Структура

ChatsPage
├── Container (wrapper)
│ ├── Container (sidebar)
│ │ └── ChatList
│ └── Container (content)
│ ├── ChatWidget (если выбран чат)
│ └── Пустое состояние (если чат не выбран)

## Особенности

✅ Соответствует архитектуре FSD
✅ Использует entities/Chat для данных
✅ Использует widgets/Chat для диалога
✅ Управляет состоянием поиска и выбранного чата
✅ Полностью клиентский компонент (use client)

🎯 Общие особенности

# Архитектура

FSD: Чёткое разделение на слои
entities/Chat — данные и бизнес-логика
widgets/Chat — составные блоки интерфейса
pages/ChatsPage — страница приложения

# Производительность

✅ React.memo для предотвращения лишних рендеров
✅ useCallback для стабильных ссылок на функции
✅ useMemo для мемоизации вычислений
✅ Оптимизированные стили с минимальными перерасчётами

# Доступность (a11y)

✅ role, aria-label, aria-live для скринридеров
✅ Состояния focus-visible для клавиатурной навигации
✅ Семантически правильные теги
✅ Поддержка горячих клавиш

# Стили
