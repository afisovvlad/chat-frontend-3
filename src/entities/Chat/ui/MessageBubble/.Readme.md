# `MessageBubble`

Компонент отображает сообщение в чате.

**Пропсы:**

- `id: string` - уникальный идентификатор сообщения
- `time: number` - время сообщения (UNIX)
- `text: string` - текст сообщения
- `status: 'received' | 'sending' | 'unread' | 'read'` - статус сообщения
- `onClick: (id: string) => void` - обработчик клика
- `isGroupChat?: boolean` - флаг группового чата
- `senderName?: string` - имя отправителя (для группового чата)
- `senderAvatar?: string` - аватар отправителя (для группового чата)
- `isFirstInGroup?: boolean` - первое сообщение в группе от отправителя
- `isLastInGroup?: boolean` - последнее сообщение в группе от отправителя

**Поведение:**

- Обычные чаты или отправленные сообщения в групповых - без изменений
- Групповые сообщения `received`:
  - одиночное - имя сверху, аватар снизу
  - несколько подряд - верхнее: имя, нижнее: аватар, средние: только текст, отступ под аватар

- Имя и аватар внутри `message`
- Текст + время в одной строке

**Как родителю правильно передавать флаги:**

Если сообщений несколько подряд от одного отправителя:

- верхнее -> `isFirstInGroup = true`, `isLastInGroup = false`
- средние -> `false / false`
- нижнее -> `false / true`
- одиночное -> `true / true`

Если статус не `received` - оба флага могут быть любыми, они не влияют на UI.
